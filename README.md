# 3D p-Dispersion of Spheres

Simulation code for distributing \(n\) spheres in \(\mathbb{R}^3\),
maximizing a minimum–distance (\(p\)-dispersion) criterion and
studying their motion under custom dynamics.

## Structure

- **src/**: core modules  
- **notebooks/**: interactive exploration  
- **tests/**: unit + integration tests  
- **requirements.txt**: pinned dependencies
